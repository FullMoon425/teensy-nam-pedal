# 03_knobs_switches

포트 3개, EC11 인코더(푸시), 풋스위치, 상태 LED를 브레드보드에 연결해 확인합니다 (H2).

## 배선 (hardware-design.md 5장 초안)
| 부품 | 연결 |
|---|---|
| 포트 1/2/3 (B10K) | 양끝 3.3V / AGND, 와이퍼 → 1kΩ → 핀 14 / 15 / 16, 핀에 0.1µF to GND |
| 인코더 A / B / SW | 핀 2 / 3 / 4, 공통 핀은 GND, 각 핀 10nF to GND |
| 풋스위치 | 핀 5 ↔ GND, 100nF 병렬 |
| LED | 핀 9 → 1kΩ~2.2kΩ → LED → GND |

**포트 양끝은 반드시 3.3V**에 연결하세요. 5V를 넣으면 Teensy가 망가집니다.

## 통과 기준
- 포트 3개 모두 끝에서 끝까지 0%~100% 근처로 움직이고, 손을 떼면 값이 떨리지 않음
- 인코더 한 칸에 1씩 바뀜 (2씩 바뀌면 코드의 `/ 4`를 `/ 2`로 바꾸고 기록)
- 인코더 버튼과 풋스위치가 짧게/길게를 구분함, 길게는 600ms에 바로 찍힘
- 풋스위치 짧게 누를 때마다 LED 토글
