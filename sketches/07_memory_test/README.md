# 07_memory_test

Teensy 4.1의 메모리 영역을 검증하고 속도를 잽니다. 부품은 Teensy 4.1만 있으면 되고, PSRAM은 뒷면 패드에 칩을 붙였을 때만 검사합니다.
결과(특히 속도)는 NAM 가중치와 상태 버퍼를 어느 영역에 둘지 정할 때 참고합니다.

| 영역 | 검사 범위 | 캐시 |
|---|---|---|
| RAM1 (DTCM) | 정적 시험 버퍼 256KB | 없음 (CPU 직결) |
| RAM2 (OCRAM) | 힙에서 한 번에 잡을 수 있는 가장 큰 블록 | 있음 (쓰기 뒤, 읽기 전에 캐시 비움) |
| PSRAM | EXTMEM 변수 뒤부터 끝까지 (장착 시) | 있음 |

패턴은 주소, ~주소, 0x00, 0xFF, 0x55, 0xAA, 의사난수 7가지입니다. 패스마다 시드가 바뀌고, `loop()`가 패스를 계속 반복합니다.

## 실행
```bash
pio run -d sketches/07_memory_test -t upload && pio device monitor -b 115200
```

## 시리얼 출력
- 시작할 때 CPU 클럭과 메모리 맵이 나옵니다: 플래시 이미지, ITCM, DTCM 사용량, 스택 여유, RAM2 정적/힙, PSRAM 크기.
- 직전 실행이 하드폴트로 재부팅됐으면 `CrashReport` 내용이 먼저 찍힙니다.
- 패스마다 영역별로 `주소 / 크기 / 쓰기 MB/s / 읽기 MB/s / OK 또는 FAIL (오류 수)`이 나옵니다.
- 틀린 워드는 영역마다 처음 8개까지 주소와 기대값, 읽은 값이 찍힙니다.

## 통과 기준
- 모든 영역이 `OK`이고, 여러 패스(최소 10패스 권장)를 돌려도 누적 오류가 0
- 영역별 쓰기/읽기 MB/s를 기록 (RAM1이 가장 빠르고, PSRAM이 가장 느린 것이 정상)
- PSRAM을 붙였다면 메모리 맵에 크기(8MB 또는 16MB)가 나옴

## LED
- 패스가 도는 동안 켜지고, 패스 사이 2초 동안 꺼집니다.
- 오류가 한 번이라도 나면 패스 사이에 빠르게 깜빡입니다.

## 안 될 때
- PSRAM이 `없음`으로 나옴: 칩 납땜(특히 패드 브리지나 냉납)과 칩 종류(APS6404L 등 Teensy 4.1 호환 QSPI PSRAM)를 확인합니다.
- PSRAM에서만 오류가 남: 납땜 불량일 가능성이 가장 큽니다. 같은 주소 비트에서 반복되는지 오류 주소를 확인합니다.
- 패스 도중 재부팅됨: 다음 부팅 때 찍히는 `CrashReport`를 확인합니다.
