# 02_audio_passthrough

Teensy 4.1 + PJRC Audio Shield Rev D. 실드 납땜과 코덱 동작을 확인합니다.

## 연결
- 실드 LINE IN L ← 기타 (아직 입력 버퍼가 없으므로 짧은 케이블로 테스트. 폰 음악 출력도 됨)
- 실드 LINE OUT L → 앰프 인풋 또는 액티브 스피커. 간단히는 실드 헤드폰 잭에 이어폰
- 실드 핀: I2S 7, 8, 20, 21, 23 / I2C 18, 19 (다른 용도로 쓰지 않음)

## 통과 기준
- 입력 소리가 잡음 없이 그대로 나옴
- 시리얼에 CPU 1~2% 안팎, 오디오 메모리 최대 4 이하가 찍힘
- 기타를 세게 쳐도 찌그러지지 않는 `LINE_IN_LEVEL` 값을 찾아 [hardware-design.md](../../docs/hardware-design.md) 3-1절에 기록

## 안 될 때
- 소리가 전혀 안 나면: 실드 핀헤더 납땜(특히 7, 8, 20, 21, 23) 확인
- 험(웅~) 잡음: 노트북 충전기를 빼고 배터리로 테스트해서 접지 루프인지 확인
