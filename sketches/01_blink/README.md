# 01_blink

Teensy 4.1 단독. 업로드 환경이 제대로 잡혔는지 확인합니다.

## 통과 기준
- 보드 주황색 LED가 0.5초 간격으로 깜빡임
- 시리얼 모니터에 `CPU 클럭: 600 MHz`와 `blink 1, 2, 3...`이 찍힘

## 참고
- 보드 LED는 13번 핀인데, 13번은 OLED의 SPI SCK로도 씁니다. 그래서 OLED를 연결한 뒤에는 화면을 갱신할 때마다 보드 LED가 깜빡이거나 희미하게 켜져 보입니다. 고장이 아니고 정상입니다. 바이패스 표시는 9번 핀 LED를 씁니다.

## 안 될 때
- 포트가 안 보이면: 충전 전용 USB 케이블인지 확인 (데이터 케이블 필요)
- Linux: udev 규칙(`00-teensy.rules`) 설치
- 업로드가 멈추면: 보드의 PROGRAM 버튼을 한 번 누름
