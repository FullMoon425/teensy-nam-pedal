# 04_oled_display

Waveshare 2.23" OLED(SSD1305, 128x32, SPI)를 연결해 확인합니다 (H2).
모듈 뒷면 저항 설정이 4선 SPI(Waveshare 기본값)인지 먼저 확인하세요.

## 배선
| OLED 핀 | Teensy 핀 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SDA / MOSI / DIN | 11 |
| SCL / SCK / CLK | 13 |
| CS | 10 |
| DC | 24 |
| RES / RST | 25 |

## 통과 기준
- HOME 화면(프리셋 줄 + 노브 3개 라벨/값 + 오른쪽 IN/OUT 미터)이 깨지지 않고 표시됨
- 노브 페이지가 2초마다 EQ(Bass/Mid/Treb) ↔ IN/OUT(Gain/Gate/Mstr)으로 바뀌고, 미터 막대가 움직임 (값과 레벨은 테스트용 가짜 값)
- 시리얼에 찍히는 1프레임 전송 시간(평균/최대)과 실제 fps(20 근처) 기록 (오디오와 함께 돌 때 영향 판단용)
- 02 패스스루와 같이 연결했을 때 화면 갱신 중 '찌직' 잡음이 들리는지 확인하고 기록

`src/main.cpp`의 `HOME_LINES`로 배치를 고릅니다: 3 = 6x10 글꼴(프리셋/라벨/값), 4 = 5x7 글꼴(모델 파일명 줄 추가).
CPU%·샘플레이트 표시는 HOME에서 빼고 나중에 별도 화면에서 만듭니다.

## 안 될 때
- 화면이 좌우로 2픽셀 밀리거나 가장자리가 잘리면: `src/main.cpp`에서 생성자를 `ADAFRUIT` 줄 대신 주석 처리된 `NONAME` 줄로 바꿈 (x 오프셋 4 → 2)
- 위아래가 반만 나오거나 줄이 겹치면: 모듈이 128x32가 아님. 생성자 해상도 확인
- 아무것도 안 나오면: VCC가 3.3V인지, 모듈 뒷면 저항이 SPI 쪽인지(I2C로 되어 있으면 SPI로 옮김), 실크 인쇄 이름대로 SCK/MOSI를 꽂았는지 확인
- 화면이 흐리거나 깨지면: RST(25) 배선, SPI 선 길이(브레드보드 점퍼는 10cm 이내 권장)
- 화면 갱신 때 보드 LED(13번)가 깜빡이는 것은 SCK 공용 때문이며 정상
