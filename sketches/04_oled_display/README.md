# 04_oled_display

1.3" OLED 128x64 SPI(SH1106 또는 SSD1306)를 연결해 확인합니다 (H2).

## 배선
| OLED 핀 | Teensy 핀 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SDA / MOSI / DIN | 11 |
| SCL / SCK / CLK | 13 |
| CS | 10 |
| DC | 24 |
| RES / RST | 25 |

## 통과 기준
- HOME 화면 예시가 깨지지 않고 표시되고 frame 숫자가 올라감
- 시리얼에 찍히는 1프레임 전송 시간 기록 (오디오와 함께 돌 때 영향 판단용)
- 02 패스스루와 같이 연결했을 때 화면 갱신 중 '찌직' 잡음이 들리는지 확인하고 기록

## 안 될 때
- 화면 왼쪽 2픽셀이 잘리거나 밀리면: SSD1306 모듈일 가능성. 생성자를 SSD1306으로 변경
- 아무것도 안 나오면: 모듈이 I2C 전용인지 확인 (핀 이름에 CS/DC가 없으면 I2C 모듈)
