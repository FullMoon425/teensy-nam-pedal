# 08_ui_integration

[03_knobs_switches](../03_knobs_switches)의 조작계와 [04_oled_display](../04_oled_display)의 화면을 같이 연결해, HOME 화면 동작([software-design.md](../../docs/software-design.md) 8-1~8-3절)을 오디오 없이 확인합니다 (H2).
**03과 04를 각각 통과한 뒤에** 돌립니다. 여기서 문제가 생기면 03/04 단독으로 돌려 원인을 가릅니다.

## 배선
03과 04 배선을 그대로 합칩니다. 겹치는 핀은 없습니다.

| 부품 | 핀 |
|---|---|
| 포트 1/2/3 | 14 / 15 / 16 |
| 인코더 A / B / SW | 2 / 3 / 4 |
| 풋스위치 | 5 |
| 상태 LED | 9 |
| OLED MOSI / SCK / CS / DC / RST | 11 / 13 / 10 / 24 / 25 |

## 조작
| 조작 | 동작 |
|---|---|
| 포트 1/2/3 | 현재 페이지의 파라미터 3개. 돌리면 1.5초 큰 글씨 팝업 |
| 인코더 회전 | 프리셋 미리보기 (첫 줄 반전). 짧게 누르면 로드, 3초 무조작이면 취소 |
| 인코더 짧게 | 노브 페이지 EQ(Bass/Mid/Treb) ↔ IN/OUT(Gain/Gate/Mstr) |
| 인코더 길게 | MENU (이 스케치에는 없음, 시리얼에만 출력) |
| 풋스위치 짧게 | 바이패스 토글. LED 켜짐 = 이펙트 켜짐, 바이패스면 첫 줄 오른쪽에 BYP |
| 풋스위치 길게 | 다음 프리셋 (600ms에 바로) |

페이지나 프리셋이 바뀌면 포트 3개가 **잠깁니다(캐치)**. 잠긴 동안 값은 `(5.0)`처럼 괄호로 표시되고, 노브가 저장값을 지나가거나 ±2% 안에 들어오면 풀립니다.
프리셋 4개와 미터 레벨은 테스트용 가짜 값입니다.

## 통과 기준
- 포트를 돌리면 화면 값과 팝업이 바로 따라오고, 손을 떼면 값이 안 떨림 (03 단독일 때와 같아야 함)
- 페이지/프리셋을 바꾼 직후 포트가 잠기고(괄호 표시), 노브가 저장값을 지나가면 풀림
- 인코더 한 칸에 프리셋 1칸, 미리보기 반전 표시, 짧게 누름으로 로드, 3초 지나면 취소
- 풋스위치 짧게 = LED와 BYP 토글, 길게 = 600ms에 바로 다음 프리셋
- 시리얼 `[통계]` 줄의 전송 평균/최대 us, fps(20 근처), **루프 최대 us** 기록. 루프 최대는 입력을 못 보는 최악 시간이라 디바운스 20ms보다 충분히 작아야 함

## 안 될 때
- 03 단독에서는 안 떨리던 포트가 여기서만 떨림: OLED가 3.3V에 잡음을 싣는 것. 포트 3.3V를 Teensy 3.3V 핀에서 따로 끌어오고(OLED와 같은 브레드보드 레일 공유 피하기), 포트 GND도 따로. 그래도 떨리면 0.1µF를 포트 3.3V 끝에도 추가
- 화면이 갱신될 때마다 인코더가 칸을 놓침: Encoder 라이브러리는 핀 2/3 인터럽트로 세므로 정상이라면 놓치지 않음. 배선(10nF)과 핀 번호 확인
- 화면/입력 문제는 각각 [04](../04_oled_display/README.md#안-될-때), [03](../03_knobs_switches/README.md) 참고
