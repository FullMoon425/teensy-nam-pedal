전체 개요와 일정은 [plan.md](plan.md), 펌웨어는 [software-design.md](software-design.md)를 보세요.
표시 규칙: **(확정)** = 이대로 진행, **(확인 필요)** = 브레드보드에서 측정해 확정.

## 1. 블록 다이어그램

```
                 +9V ──┬── 오피앰프 V+ ── Vref 4.5V(분압+버퍼)
DC 잭(9V, 센터-) ─ 역극성보호 ─┤
                       └── L7805 ── +5V ── Teensy VIN ── (Teensy 내부 3.3V) ── 오디오실드, OLED, 포트

IN 잭 ─ [입력 버퍼 U1A] ─ AC결합 ─ SGTL5000 LINE IN L
                                    │ (I2S)
                                 Teensy 4.1 ─ SPI ─ OLED
                                    │        ─ ADC ─ 포트 x3
                                    │        ─ GPIO ─ 인코더, 풋스위치, LED
SGTL5000 LINE OUT L ─ AC결합 ─ [출력 버퍼 U1B] ─ SEND 잭
RETURN 잭(스위칭, 미삽입 시 SEND와 연결) ─ [출력 버퍼 U2A] ─ OUT 잭
```

## 2. 전원부 (확정)

규격: **9V DC, 2.1mm 배럴, 센터 마이너스, 500mA 이상 권장** (예상 소비 150~200mA).
근거: 페달 표준이라 기존 파워서플라이를 그대로 쓰고, 디지털 페달 평균 요구 전류 수준.

| 블록 | 부품 | 비고 |
|---|---|---|
| 역극성 보호 | P-MOSFET(예: AO3401/IRF9540 계열) 또는 1N5817 쇼트키 직렬 | MOSFET이 전압강하 적음. 쇼트키는 약 0.3V 강하 |
| 입력 필터 | 100µF 25V 전해 + 0.1µF 필름 | 잭 직후 |
| 5V 레귤레이터 | L7805(TO-220) 또는 LM2940 | 입력 0.33µF / 출력 0.1µF + 10µF. 손실 약 0.8W → 작은 방열판 또는 케이스에 부착 |
| Vref 4.5V | 10kΩ + 10kΩ 분압 + 47µF, 오피앰프 버퍼(또는 TLE2426) | 입력·출력 버퍼 공용 바이어스 |
| 오피앰프 전원 | 9V 레일에 47Ω + 100µF RC 필터 | 디지털 잡음 차단 |

- **Teensy 뒷면 VUSB–VIN 연결 패드 절단 필수.** 안 끊으면 USB 연결 시 PC 5V와 레귤레이터 5V가 충돌합니다. 끊은 뒤에는 펌웨어 업로드 때도 9V 어댑터를 꽂아야 합니다.
- 접지: 스타 접지. 오디오 접지(잭 슬리브, 오피앰프, Vref)와 디지털 접지(Teensy, OLED)를 DC 잭 근처 한 점에서 합칩니다.
- Teensy 4.1은 **5V 톨러런트가 아님**: 포트, 인코더, 풋스위치는 모두 3.3V 기준으로 배선.

## 3. 오디오 경로

### 3-1. 입력 버퍼 (U1A: TL072 또는 OPA2134)
- 비반전 유니티 게인 버퍼(전압 팔로워)로 시작. 게인은 코덱의 `lineInLevel()`로 디지털 조정.
- 입력: IN 잭 팁 → 1kΩ 직렬 → 22nF~0.1µF 결합 캐패시터 → 오피앰프 + 입력. + 입력은 **1MΩ으로 Vref에 바이어스**.
- 팁에 **10MΩ 풀다운**(잭 꽂을 때 팝 방지), 오피앰프 + 입력에 100pF to GND(RF 필터).
- 입력 임피던스 계산: 오디오 대역에서 결합 캐패시터는 거의 단락이고 Vref는 47µF로 AC 접지라, 팁에서 보면 풀다운과 바이어스 저항이 **병렬**입니다.
  - 10MΩ ∥ (1kΩ + 1MΩ) ≈ **0.91MΩ** (풀다운을 1MΩ으로 두면 1MΩ ∥ 1MΩ ≈ 0.5MΩ이 되어 패시브 픽업의 고음이 깎임)
  - 저역 차단: 1/(2π × 1MΩ × 22nF) ≈ 7.2Hz (0.1µF면 1.6Hz)
  - 100pF는 고음에서 기타 케이블 약 1m 정도의 용량 부하(10kHz에서 약 159kΩ)입니다. 고음 손실이 들리면 47pF로 줄입니다 **(확인 필요)**.
  - 바이어스 1MΩ × TL072 입력 바이어스 전류(최대 수백 pA) = 1mV 미만이라 DC 오프셋은 무시할 수 있습니다.
- 출력: 1µF~4.7µF 결합 → 1kΩ 직렬 → SGTL5000 LINE IN L.
- **(확인 필요)** 오디오실드 Rev D LINE IN 쪽에 이미 결합 캐패시터가 있는지 회로도로 확인. 있으면 중복 결합 캐패시터는 생략 가능.
- 레벨: SGTL5000 `lineInLevel(0~15)` 범위가 약 3.12Vpp~0.24Vpp (1.5dB 간격). 하이게인 험버커 피크도 2Vpp 이하라 유니티 버퍼 + `lineInLevel` 조정으로 충분할 것으로 판단 **(확인 필요: 실제 기타로 클리핑 여부 측정)**.
  - 레벨별 풀스케일(Teensy Audio `control_sgtl5000.cpp`의 `lineInLevel()` 주석): 0 = 3.12, 1 = 2.63, 2 = 2.22, 3 = 1.87, 4 = 1.58, **5 = 1.33(라이브러리 기본)**, 6 = 1.11Vpp ...
  - 라이브러리 기본값 5(1.33Vpp)는 2Vpp 가정보다 작아서 세게 치면 클리핑됩니다. 그래서 스케치와 펌웨어는 **0(3.12Vpp)에서 시작**하고, 측정한 피크에 여유 3dB 이상을 두는 가장 큰 번호로 올려서 아래에 기록합니다.
  - 측정 기록: (02 패스스루에서 측정 후 기입: 기타/픽업, 측정 피크 Vpp, 확정 `lineInLevel`)

### 3-2. 출력 버퍼 (U1B → SEND, U2A → OUT)
- SGTL5000 LINE OUT L → 결합 캐패시터(1~4.7µF) → Vref 바이어스 100kΩ → 비반전 버퍼(게인 1~2배) → 10µF 결합 → 1kΩ 직렬 → 100kΩ 풀다운 → SEND 잭 팁.
- `lineOutLevel(13~31)` 범위 약 3.16Vpp~1.16Vpp. 기본은 유니티 버퍼, 앰프 인풋 기준 레벨이 부족하면 게인 2배로 **(확인 필요)**.
- RETURN 잭: **스위칭 잭**. 플러그 미삽입 시 노멀 접점으로 SEND 신호가 들어오고, 삽입 시 외부 이펙터 신호로 대체 → U2A 버퍼 → OUT 잭. 같은 구조(결합, 1MΩ 바이어스, 직렬 1kΩ, 풀다운).
- 오디오실드 헤드폰 출력은 사용하지 않음(LINE OUT만).

### 3-3. 오피앰프 선택
| 후보 | 장점 | 단점 |
|---|---|---|
| TL072 | 싸고 구하기 쉬움, 브레드보드 시작용 | 잡음 약간 높음, 9V 단전원에서 출력 스윙 좁음 |
| OPA2134 | 저잡음 | 비쌈 |
| NE5532 | 저잡음, 구동력 좋음 | 입력 바이어스 전류 커서 1MΩ 입력에 부적합 → 출력 버퍼용으로만 |

권장: 입력 TL072(또는 OPA2134), 출력 NE5532 또는 TL072.

## 4. 바이패스

- **MVP: 디지털 바이패스** (펌웨어에서 입력을 그대로 출력, 추가 부품 없음). 단점: 전원이 꺼지면 소리 안 남.
- **확장: 릴레이 트루 바이패스.** 래칭 아닌 일반 DPDT 신호 릴레이(예: Panasonic TQ2-5V 또는 3V 계열)를 Teensy GPIO → NPN 트랜지스터(2N3904) + 플라이백 다이오드로 구동. 릴레이 미통전 상태 = 바이패스로 배선하면 전원 꺼져도 IN→OUT 연결. 전환 순간 펌웨어에서 출력 뮤트 후 전환해 팝 방지.

## 5. 조작계·디스플레이 배선

| 기능 | 부품 | 배선 |
|---|---|---|
| 작은 노브 x3 | B10K 포트 | 양끝 = 3.3V / AGND, 와이퍼 → 1kΩ → ADC 핀, 핀에 0.1µF to GND |
| 큰 노브 | EC11 인코더(푸시 포함, 디텐트 20) | A/B/SW → GPIO(내부 풀업), 각 핀 10nF to GND(하드웨어 디바운스) |
| 풋스위치 | 모멘터리 SPST 소프트터치 | GPIO(내부 풀업) ↔ GND, 100nF 병렬 |
| 상태 LED | 3mm LED | GPIO → 1kΩ~2.2kΩ → LED → GND (3.3V 구동) |
| 화면 | 1.3" OLED 128x64 SPI (SH1106 또는 SSD1306) | 3.3V 전원, SPI |

### 핀 배치 (초안, 확인 필요)
오디오실드 Rev D가 쓰는 핀은 피합니다: **7, 8, 20, 21, 23 (I2S), 18, 19 (I2C)**. 실드의 SD 슬롯·메모리 칩(6, 10~12 등)은 사용하지 않습니다(Teensy 내장 SD 사용).

| 핀 | 용도 |
|---|---|
| 14 (A0) | 포트 1 |
| 15 (A1) | 포트 2 |
| 16 (A2) | 포트 3 |
| 2, 3 | 인코더 A, B |
| 4 | 인코더 SW |
| 5 | 풋스위치 |
| 9 | 바이패스 LED |
| 11 (MOSI), 13 (SCK) | OLED SPI |
| 10 | OLED CS |
| 24, 25 | OLED DC, RST |
| 28 | (확장) 바이패스 릴레이 |

→ Phase 1에서 오디오실드 회로도와 Teensy 4.1 핀맵을 대조해 확정합니다. 실드 메모리 칩 미장착 보드면 핀 6 충돌은 없습니다.

## 6. 기구(케이스)

- 케이스: **Hammond 1590XX** (145×121mm). 1590BB(119×94mm)는 노브 4개 + OLED + 풋스위치가 들어가긴 하지만 배선이 빡빡합니다.
- 상판(위에서 볼 때): 위쪽 줄 작은 노브 3개, 가운데 OLED(가로) + 오른쪽 큰 인코더, 아래쪽 풋스위치 + LED.
- 측면: 오른쪽 IN, 왼쪽 OUT, 윗면(뒤쪽) DC + SEND + RETURN. Teensy USB는 측면 구멍 또는 패널 마운트 USB 연장 케이블로 노출해 케이스를 안 열고 펌웨어 업데이트와 MTP를 할 수 있게 합니다.
- microSD 접근: Teensy 내장 슬롯은 케이스 안이라 빼기 불편 → 패널 마운트 microSD 연장 케이블을 쓰거나, USB MTP로 파일을 넣습니다(소프트웨어 문서 참고).

## 7. 제작 단계

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| H0 | Teensy + 오디오실드 납땜, VUSB–VIN 절단 전 USB로 48kHz 패스스루 확인 | 이어폰/라인으로 소리 통과 |
| H1 | 브레드보드: 전원부 → Vref → 입력 버퍼 → 출력 버퍼 | 9V 어댑터로 기타 → 앰프 소리 깨끗, 바닥 잡음 확인 |
| H2 | 조작계·OLED 브레드보드 연결 | 펌웨어 테스트 스케치로 모든 입력 인식 |
| H3 | 만능기판(또는 PCB) 이식 | 브레드보드와 같은 동작 |
| H4 | 케이스 가공, 조립 | 전원 투입 전 저항 체크 → 전류 측정 → 소리 확인 |

PCB 주문은 배송 1~2주라, 일정이 촉박하면 **만능기판 + 기성 모듈(오디오실드, OLED 모듈, 레귤레이터)**로 마감하는 것을 권장합니다.

### 조립 후 점검 체크리스트
1. 전원 투입 전: 9V–GND, 5V–GND 저항 측정(단락 없음 확인)
2. Teensy 빼고 전원 투입: 5V, 4.5V Vref 전압 확인
3. Teensy 장착 후 소비전류 측정(200mA 안팎 정상)
4. 1kHz 사인파 입력 → SEND/OUT 파형, 클리핑 시작 레벨 측정
5. 무입력 잡음: 앰프 볼륨 올리고 화면 갱신·SD 접근 시 잡음 유무

## 9. 회로 설계용 프롬프트

새 Claude 세션에 아래 블록을 먼저 붙이고, 단계별 요청을 이어서 붙이세요.

### 공통 컨텍스트
```
너는 기타 이펙터 아날로그 회로와 임베디드 하드웨어 설계자로서 나와 함께 디지털 앰프 모델러 페달의 회로를 설계한다.

[프로젝트]
- MCU: Teensy 4.1 (3.3V 로직, 5V 톨러런트 아님), 코덱: PJRC Audio Shield Rev D (SGTL5000), LINE IN/LINE OUT만 사용.
- 전원: 9V DC 2.1mm 센터 마이너스, 역극성 보호 → L7805 → Teensy VIN (VUSB-VIN 패드 절단). 오피앰프는 9V 단전원, Vref 4.5V.
- 오디오: IN(1/4" TS) → 1MΩ 입력 버퍼 → LINE IN L. LINE OUT L → 출력 버퍼 → SEND. RETURN(스위칭 잭, 미삽입 시 SEND 신호 통과) → 출력 버퍼 → OUT. FX 루프는 아날로그.
- 조작계: B10K 포트 3개(ADC, 3.3V 기준), EC11 인코더(푸시), 모멘터리 풋스위치, 상태 LED, 1.3" OLED 128x64 SPI.
- 바이패스: MVP는 디지털, 확장으로 릴레이 트루 바이패스.
- 케이스: Hammond 1590XX. 마감은 만능기판 + 기성 모듈 우선.
- 오디오실드가 쓰는 핀(7, 8, 20, 21, 23, 18, 19)은 피한다.

[규칙]
- 부품 값마다 근거(계산식)를 붙인다.
- 데이터시트·회로도로 확인해야 하는 사실은 추측하지 말고 "확인 필요"로 표시하고 확인 방법을 제시한다.
- 회로는 넷리스트(부품 - 연결 노드) 표로 주고, 브레드보드 테스트 순서와 측정 방법을 함께 준다.
- 답변은 한국어로.

[지금까지 결정된 것]
- (단계가 끝날 때마다 여기에 추가)
```

### H1-a 전원부
```
전원부를 설계해줘: 역극성 보호(P-MOSFET vs 쇼트키 비교 후 선택), 입력 필터, L7805 방열 계산(입력 9V, 부하 200mA), Vref 4.5V 생성과 버퍼링, 오피앰프 레일 RC 필터, 스타 접지 배치. 넷리스트와 측정 체크리스트로.
```

### H1-b 입력/출력 버퍼
```
입력 버퍼와 출력 버퍼 2개를 설계해줘.
1. 먼저 Audio Shield Rev D 회로도 기준으로 LINE IN/LINE OUT의 결합 캐패시터 유무, 입력 임피던스, 레벨 범위(lineInLevel, lineOutLevel)를 정리해줘.
2. 입력: 1MΩ, 팝 방지, RF 필터, 하이게인 험버커에서도 클리핑 없는 게인 설정.
3. 출력: SEND와 OUT 각각, 직렬 1kΩ, 풀다운, RETURN 스위칭 잭 노멀 배선.
4. 각 단의 헤드룸(9V 단전원 TL072 기준 출력 스윙)과 예상 잡음 레벨.
```

### H2 조작계·핀 배치
```
Teensy 4.1 핀 배치를 확정해줘. 오디오실드 Rev D가 실제로 쓰는 핀을 회로도로 확인하고, 포트 3개(ADC), 인코더 A/B/SW, 풋스위치, LED, OLED SPI(CS/DC/RST), 확장용 릴레이 핀을 배정해줘. 각 입력의 하드웨어 디바운스/필터 값과 근거도 함께.
```

### H3 만능기판·케이스
```
브레드보드 회로를 만능기판으로 옮기는 레이아웃과 Hammond 1590XX 가공도를 만들어줘.
- 상판: 포트 3개, OLED, 인코더, 풋스위치, LED 위치(mm). 측면/윗면: IN, OUT, SEND, RETURN, DC, USB 연장 위치.
- 기판 높이와 포트·OLED 간섭 확인, 디지털/아날로그 영역 분리, 접지 배선.
- 조립 후 점검 순서.
```

### H4 (확장) 릴레이 트루 바이패스
```
Teensy GPIO로 구동하는 DPDT 신호 릴레이 트루 바이패스를 설계해줘. 미통전 = 바이패스(전원 꺼져도 소리 통과), 트랜지스터 드라이버와 플라이백 다이오드, 전환 팝 방지를 위한 펌웨어 뮤트 타이밍까지.
```
